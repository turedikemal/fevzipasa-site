# Fevzipaşa Tasarım Pazarı

MA Quilts yönünden uyarlanan ilk taslak: beyaz zemin, turuncu tipografi, sarı ve pembe fotoğraf alanı. Mobil menü, katılımcılar, konum bağlantısı ve 9–11 Ekim 2026 takvim dosyası.

## Başlatma

Node.js 18 veya üzeri gerekir. Paket kurulumu gerekmez.

```bash
npm run dev
```

Tarayıcı Mac'te otomatik açılır. Başlangıç portu 3001; doluysa sonraki uygun port denenir. Terminaldeki adresi kullanın. Control + C ile durdurun.

Alternatif: `bash BASLAT.command`. Kurulum olmadan `index.html` dosyası da açılabilir.

Ürün görseli temsilidir. Konum bağlantısı mahalleyi gösterir; kesin etkinlik noktası ve gerçek katılımcı fotoğrafları sonraki düzenlemede eklenecektir. Google Fonts için internet gerekir; çevrimdışı sistem fontu kullanılır.
